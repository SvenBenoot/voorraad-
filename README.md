# Voorraad · Van Gils

Web-app om de voorraad in de bestelwagen bij te houden met QR-codes. Werkt op iPhone en Android, ook zonder internet.

Je gegevens staan enkel op je eigen toestel, niet in deze repository. Maak in Instellingen geregeld een reservekopie naar iCloud Drive.
